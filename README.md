# Ревизия

Браузерная игра про садоводческое товарищество. Ты член ревизионной комиссии СНТ «Синий учитель», в садоводстве известный как Болгарин. Сегодня общее собрание, и до восемнадцати ноль-ноль нужно собрать подписи под актом: председатель построил баню на взносы, провёл кабель мимо счётчика и подвинул забор на три сотки общего проезда.

**Играть: https://panbit24.github.io/revizia-snt/**

Ничего скачивать и устанавливать не надо. Работает и с телефона.

> Игра для взрослых: мат, алкоголь и дачные нравы.

## Как играть

У тебя есть день с 8:30 до 18:00, 100 нервов и два пузыря. Нужно семь подписей, а участков, которые их дают, девять — какие обходить, решаешь сам: важно количество, а не состав. С 13:00 до 14:00 мёртвый час, все спят, время идёт.

Три вещи, которые стоит знать сразу:

- **Долбиться выгодно.** Каждый уход без подписи повышает шанс на следующей попытке. Увидел «он уже подустал от тебя» — дожимай.
- **Дома тебя не пожалеют.** Вика и Лерка только добьют, зато в сарае за банками есть заначка.
- **Отдыхать надо у Лёхи, Чриса и Танкиста.** Лёха отдаёт свой велик, а сам убегает трусцой — минус три минуты с каждого перехода до конца дня, — а ещё его можно позвать с собой к тому, кто упёрся: он заходит первым. Танкиста пилит жена Юлька, так что пожаловаться друг другу на своих — отдельная терапия.

## Как устроено

| Файл | Что внутри |
|---|---|
| `index.html` | собранная игра, один файл, без зависимостей |
| `src/index.html` | движок, вёрстка, стили |
| `src/content-18.js` | сюжет про СНТ (18+) |
| `src/content.js` | приличный сюжет про офис и списание чайника |
| `build.js` | сборка `index.html` из `src/` |

Движок ничего не знает про сюжет: участки, персонажи, реплики и исходы лежат в файле контента, и новый персонаж добавляется одним объектом в массив. Смена сеттинга целиком — с офиса на садоводство — не потребовала правок логики.

Пересобрать после правки контента:

```bash
node build.js              # сюжет 18+
node build.js content.js   # приличный
```

## Формат контента

Участок — объект в `GAME.offices`:

```js
{
  id: 'metrolog',
  room: 'Участок 5',
  name: 'Поверка счётчиков',
  official: 'Эдуард Ильич',
  emoji: '📏',
  required: true,          // даёт подпись и идёт в зачёт квоты
  time: 15,                // минут на одно действие здесь
  intro: 'Текст при первом визите.',
  intro2: 'Текст при повторном.',
  options: [
    {
      text: 'Реплика игрока.',
      need: 'akt_schetchika',   // без предмета кнопка заблокирована
      once: true,               // срабатывает раз за партию
      outcomes: [
        { w: 3, text: 'Что произошло.', nerves: -10 },
        { w: 1, text: 'Повезло.', stamp: true },
      ],
    },
  ],
}
```

`outcomes` выбираются случайно по весам `w`. Поля исхода, все необязательные: `stamp` (подпись), `nerves`, `time`, `chocolate`, `give`/`take` (предмет), `reveal` (открыть скрытый участок), `set` (эффект на всю партию, например `{ travelCost: 2 }`).

## Баланс

Проверялся ботом в headless Chromium: 48% побед при осмысленной игре против 8% при случайных кликах, на выборке 500 партий. Если правишь контент — перепроверяй на 400+ партиях: на 200–300 разброс достигает 6 п.п. и легко принять шум за поломку.
